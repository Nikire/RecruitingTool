# Primeros Pasos con Borderless

Bienvenido a **Borderless** — tu plataforma de reclutamiento para encontrar, evaluar y contratar a las personas adecuadas. Esta guía te mostrará todo lo que necesitas saber para gestionar tu proceso de contratación de principio a fin.

---

## El Flujo Completo de Contratación

Cada contratación en Borderless sigue el mismo camino. Entender este flujo es la clave para usar la plataforma de forma efectiva.

```
Posición de Trabajo → Aplicación → Proceso de Contratación → Contratado ✓
```

Esto es lo que significa cada paso:

### 1. Creas una Posición de Trabajo
Una **Posición de Trabajo** es un puesto abierto en tu empresa — por ejemplo, *"Desarrollador Frontend"* o *"Representante de Ventas"*. Defines el título, la descripción, los requisitos y configuras las etapas de evaluación (p. ej. Screening → Entrevista Técnica → Entrevista Final).

Una vez publicado, el puesto aparece en la **Página de Empleos** pública, donde los candidatos pueden encontrarlo y postularse.

### 2. Un Candidato se postula → Aplicación
Cuando alguien se postula a través de la Página de Empleos, se crea una **Aplicación**. Esta vincula a un **Candidato** (la persona) con una **Posición de Trabajo** (el puesto al que aspira).

También puedes agregar candidatos manualmente si llegan por referencia, LinkedIn o correo electrónico, y crear la aplicación tú mismo.

Desde la sección de **Aplicaciones** revisas su perfil, ves su CV y decides:
- ✅ **Aceptar** — avanzarlos al proceso de contratación
- ❌ **Rechazar** — cerrar la aplicación

### 3. Aceptas → Inicia el Proceso de Contratación
Cuando **aceptas** una aplicación, Borderless crea automáticamente un **Proceso de Contratación** para ese candidato. El sistema copia todas las etapas que definiste en la posición y crea un pipeline personal para este candidato.

El candidato también recibe un correo con un enlace para hacer seguimiento de su propio progreso.

A partir de aquí los avanzas etapa por etapa — agregando notas, programando entrevistas y usando la puntuación de IA para apoyar tu decisión.

### 4. Resultado: Contratado o Rechazado
En cualquier momento durante el proceso de contratación puedes:
- **Marcar como Contratado** — el candidato queda cerrado como contratado y la posición puede cerrarse
- **Rechazar** — el proceso termina y el candidato es notificado

## Navegación Rápida

| Sección | Qué encontrarás |
|---------|----------------|
| **Dashboard** | Estadísticas generales, aplicaciones recientes, acciones rápidas |
| **Aplicaciones** | Todas las aplicaciones entrantes para revisar |
| **Candidatos** | Tu base de datos completa de candidatos |
| **Posiciones de Trabajo** | Puestos abiertos, etapas y seguimiento de aplicaciones |
| **Procesos de Contratación** | Pipelines activos de candidatos en evaluación |

| **Calendario** | Vista del calendario de toda la empresa |
| **Análisis** | Métricas e informes de contratación |
| **Plantillas de Correo** | Personaliza los correos automáticos a candidatos |

## Lista de Primeros Pasos

Si estás configurando Borderless por primera vez:

1. **Configura tu Perfil de Empresa** — agrega el nombre, logo y descripción de tu empresa (Configuración → Perfil de Empresa)
2. **Crea tu primera Posición de Trabajo** — define el puesto y las etapas de evaluación
3. **Comparte el enlace de la Página de Empleos** — los candidatos pueden postularse directamente desde ahí
4. **Revisa las Aplicaciones entrantes** — acepta las que valga la pena evaluar
5. **Gestiona los Procesos de Contratación** — avanza candidatos por las etapas, agrega notas, programa entrevistas
6. **Toma tu decisión** — contrata o rechaza, y cierra el proceso

> **Consejo:** También puedes agregar candidatos manualmente sin pasar por la página de empleos pública. Ve a **Candidatos → Agregar Candidato** y llena su información directamente.
