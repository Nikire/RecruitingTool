## Technical Recording Notes

### Screen Recording Setup

**Resolution:**
- Record at **1920x1080 (Full HD)** minimum
- Export at **1920x1080** for YouTube, **3840x2160 (4K)** for premium quality
- Use 16:9 aspect ratio

**Software Recommendations:**
- **macOS:** QuickTime Player (built-in), or ScreenFlow (professional)
- **Windows:** OBS Studio (free), Camtasia (professional)
- **Linux:** SimpleScreenRecorder, OBS Studio

**Frame Rate:**
- 30 FPS minimum, 60 FPS preferred for smooth UI animations
- Export at 30 FPS for web (smaller file size)

**Recording Tips:**
1. **Clean desktop** - Hide all icons, close unnecessary apps
2. **Disable notifications** - Turn on Do Not Disturb mode
3. **Browser zoom** - Set to 100% (not 110% or 90%)
4. **Clear browser cache** - Fresh session, no autofill surprises
5. **Practice run** - Record full demo 2-3 times before final take
6. **Segment recording** - Record each scene separately for easier editing
7. **Mouse highlighting** - Use mouse pointer highlight tool (yellow circle on click)

### Browser Setup for Recording

**Recommended Browser:** Chrome or Firefox (latest version)

**Extensions to Disable:**
- Ad blockers (can cause layout shifts)
- Developer tools extensions
- Privacy tools that inject UI elements

**Window Size:**
- Set browser to exactly 1920x1080 viewport
- Use responsive design mode to simulate mobile (Scene 5)

**Console Cleanup:**
- Open DevTools, clear console before recording
- Close DevTools before recording (unless showing debug info)

### Dummy Data Preparation

**Create realistic demo data:**
1. **Company:** "TechCorp Solutions" (fictional but professional)
2. **Job Positions:**
   - "Senior React Developer" (demo job)
   - "Product Manager"
   - "UX Designer"

```bash
yarn reset-db
# Then manually seed with demo data
```

### Audio Recording

**Microphone:**
- Use external USB microphone (Blue Yeti, Audio-Technica AT2020, or similar)
- Avoid laptop built-in mic (low quality, ambient noise)
- Record in quiet room, minimize echo (close to soft surfaces)

**Audio Software:**
- **Audacity** (free, cross-platform) - Record voiceover separately
- **Adobe Audition** (professional) - Noise reduction, EQ
- **GarageBand** (macOS) - Simple and effective

**Recording Settings:**
- **Sample rate:** 48kHz
- **Bit depth:** 24-bit
- **Format:** WAV (lossless) or FLAC

**Audio Processing:**
1. **Noise reduction** - Remove background hum/hiss
2. **Compression** - Even out volume levels
3. **EQ** - Boost clarity (200Hz cut, 3kHz boost)
4. **Normalization** - Set peak to -3dB (avoid clipping)
5. **Export as MP3** - 320kbps for final video

**Recording Tips:**
- **Read the script 3-4 times** before recording
- **Stand up while recording** - Better voice projection
- **Hydrate** - Drink water, avoid milk/dairy (phlegm)
- **Warm up** - Practice tongue twisters, vocal exercises
- **Record in segments** - Match each scene, easier to edit
- **Pause between sentences** - Easier to cut/splice in editing
- **Re-record mistakes** - Don't restart entire script

### Background Music

**Royalty-Free Music Sources:**
- **Epidemic Sound** - $15/mo subscription, high-quality
- **Artlist** - $199/year, unlimited downloads
- **YouTube Audio Library** - Free, limited selection
- **Bensound** - Free with attribution
- **Uppbeat** - Free tier available

**Music Style:**
- Modern, upbeat, corporate
- Subtle, not distracting (background layer, not foreground)
- No lyrics (distracting from voiceover)
- 120-130 BPM (matches energy without being frantic)

**Volume Levels:**
- Voiceover: -6dB to -3dB (loud and clear)
- Background music: -24dB to -18dB (subtle presence)
- Ensure music doesn't overpower voice

**Recommended Tracks:**
- "Corporate Success" (uplifting, professional)
- "Inspiring Innovation" (modern, tech-focused)
- "Business Growth" (confident, optimistic)

### Video Editing

**Software Recommendations:**
- **Beginner:** iMovie (macOS), DaVinci Resolve (free, all platforms)
- **Intermediate:** Final Cut Pro (macOS), Premiere Pro (subscription)
- **Professional:** DaVinci Resolve Studio, Premiere Pro

**Editing Workflow:**
1. **Import screen recordings** (one per scene)
2. **Import voiceover audio** (one per scene)
3. **Sync audio to video** - Match voiceover timing to screen actions
4. **Add transitions** - Simple fades (0.5-1 second), no flashy effects
5. **Add on-screen text** - Key points, pricing, URLs
6. **Add background music** - Fade in at Scene 2, fade out at Scene 10
7. **Color correction** - Ensure consistent brightness/contrast
8. **Add logo/branding** - Intro and outro

**Timeline Structure:**
```
Layer 4: On-screen text overlays
Layer 3: Voiceover audio
Layer 2: Background music
Layer 1: Screen recording video
```

**Transitions:**
- Scene 1 → Scene 2: Fade to white (0.5s)
- Scene 2 → Scene 3: Simple cut or crossfade (0.3s)
- Scenes 3-9: Quick cuts or crossfades (0.3s)
- Scene 9 → Scene 10: Fade to black, then fade to CTA screen (1s)

**On-Screen Text Styling:**
- **Font:** Sans-serif (Helvetica, Arial, Roboto)
- **Size:** 48-60pt for titles, 32-40pt for subtitles
- **Color:** White text with 50% black background box (readable over any UI)
- **Animation:** Fade in (0.3s), hold (2-3s), fade out (0.3s)
- **Position:** Lower third of screen (avoid covering UI)

**Pacing:**
- Keep cuts snappy (don't linger on screens)
- Match voiceover rhythm
- Use B-roll (multiple angles of same feature) to maintain visual interest
- Show mouse movement deliberately (not too fast, not too slow)

### Export Settings

**YouTube/Web Upload:**
- **Format:** MP4 (H.264 codec)
- **Resolution:** 1920x1080 (1080p)
- **Frame rate:** 30 FPS
- **Bitrate:** 8-10 Mbps (high quality)
- **Audio:** AAC, 320kbps, stereo

**4K Version (optional):**
- **Resolution:** 3840x2160 (4K)
- **Bitrate:** 20-25 Mbps
- **Everything else same**

**File Size Estimates:**
- 4-minute video at 1080p: ~250-300 MB
- 4-minute video at 4K: ~600-800 MB

### Accessibility

**Add captions/subtitles:**
1. Export voiceover script as SRT file
2. Upload to YouTube - auto-sync captions
3. Manually review and fix timing
4. Ensure accuracy (proper punctuation, no typos)

- 85% of Facebook videos watched on mute (captions critical)
- SEO boost (YouTube indexes captions)
- Accessibility compliance
- Better comprehension for non-native speakers
