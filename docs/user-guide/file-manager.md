# File Manager

Guide to viewing, downloading, and managing all company files in one place.

## Overview

The File Manager provides a centralized view of every file stored under your company account. This includes resumes uploaded by candidates, documents submitted through the careers page, and any files attached directly to candidate profiles by your HR team.

**Key capabilities:**
- View all company files in a sortable, filterable table
- Open or preview any file directly in the browser
- Filter files by type (documents, images, or other)
- Select multiple files and download them as a ZIP archive
- Delete individual files or bulk-delete multiple files at once
- Monitor your company's storage usage at a glance

## Navigating to the File Manager

1. Log in to the HR panel.
2. In the sidebar, click **Files** (or navigate directly to `/hr/files`).

The page loads with all company files shown in a data table. Files are paginated with 25 rows per page by default; you can change this to 50 or 100 using the rows-per-page control at the bottom of the table.

## Storage Quota Banner

At the top of the page, a quota banner shows your current storage consumption relative to your plan's limit. The bar changes color as usage increases:

- **Green** — below 70% of the limit
- **Yellow** — between 70% and 90%
- **Red** — above 90% or limit exceeded

If you are on the Enterprise plan the banner shows "Unlimited" and no bar is rendered. To increase your storage limit, upgrade your subscription at `/hr/billing`.

## Table Columns

| Column | Description |
|--------|-------------|
| File Name | Original file name. Click to open the file in a new browser tab. |
| Type | Categorized as **Document**, **Image**, or **Other**, shown as a color-coded chip. |
| Size | File size formatted as B, KB, or MB. |
| Candidate | Name of the candidate this file belongs to. Click the name to open the candidate profile. Shows a dash if the file is not linked to a candidate. |
| Uploaded By | Name of the HR user who uploaded the file. Shows "Public upload" for files submitted through the careers page application form. |
| Date | The date the file was uploaded. |
| Actions | Quick-action buttons: open/preview the file or delete it immediately. |

## Filtering by File Type

Use the **Filter by Type** dropdown in the toolbar to narrow the table to a specific category:

- **All Types** — show every file (default)
- **Documents** — PDF, Word (.doc/.docx), and plain-text files
- **Images** — any image file (PNG, JPG, WEBP, etc.)
- **Other** — any file that does not match the above categories

The filter applies instantly without reloading the page.

## Opening and Previewing Files

Click the file name in the table to open it in a new browser tab using the secure view endpoint (`/api/files/:uid/view`). The file renders inline when the browser supports the format (e.g., PDF), or prompts a download for unsupported types.

You can also click the open icon in the **Actions** column to achieve the same result.

## Selecting Files

Check the checkbox at the left of any row to select that file. Use the checkbox in the column header to select or deselect all currently visible files. The toolbar shows a count of how many files are selected.

## Downloading Files as a ZIP

1. Select one or more files using the checkboxes.
2. Click **Download Selected** in the toolbar.
3. A ZIP archive containing all selected files is generated by the server and downloaded to your computer.

The button is disabled when no files are selected or while a download is already in progress.

## Deleting Files

### Delete a Single File

Click the red delete icon in the **Actions** column of any row. The file is deleted immediately without a confirmation prompt.

### Bulk Delete

1. Select one or more files using the checkboxes.
2. Click **Delete Selected** in the toolbar.
3. A confirmation dialog appears listing how many files will be deleted.
4. Click **Delete** to confirm. The operation is irreversible.

Deleted files are permanently removed from storage and cannot be recovered.

## Related API Endpoints

For integrations and advanced workflows, the following backend endpoints back the File Manager:

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/files/company` | List all files for the authenticated company |
| GET | `/api/files/company/storage` | Get storage usage statistics |
| GET | `/api/files/:uid/view` | View or stream a single file |
| POST | `/api/files/download-zip` | Generate a ZIP of selected files |
| DELETE | `/api/files/:uid` | Delete a single file |
| DELETE | `/api/files/bulk` | Delete multiple files by UID |
